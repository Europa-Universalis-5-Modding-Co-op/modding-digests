# Release 1.1.0
## Breaking Changes
- Replaced `annexation_speed` modifier into `annexation_speed_base` and `annexation_speed_modifier`
- The `has_doom` trigger now needs to be run on a country and not on a religion
- Removed `{any|every|random|ordered}_culture_in_group` iterator
- Removed `unit_has_leader` trigger
## Type Documentation
### Building Types
- Added `is_indestructible` to documentation
### Country Interactions
- Added `union` to the allowed `type` list
### Formable Countries
- Changed default value of `capital_required` from `yes` to `no`
### International Organizations
- Added `can_annex_visible` to documentation
### Resolutions
- Added `ai_will_select` to documentation
### Scripted Relations
- Added `union` to the allowed `type` list
### Subject Types
- Added `can_be_annexed` to documentation
