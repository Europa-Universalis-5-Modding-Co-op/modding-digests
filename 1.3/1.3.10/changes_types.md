# Release 1.3.10 - Type Documentation
## AI scripted expansion score and target
 - New types
## Artist types
 - Added `modifier` block, which applies to hiring country
## Building types
 - Added `audio_category` and `audio_tier`
## Casus belli
 - Added `ai_wait_with_sending_peace` trigger block, which makes ai wait with sending peace unless the war is stalled out
## Chivalric orders
 - New type (no readme file)
## Interational organization land ownership
 - Added `removed_by_peace_treaty` and `remove_war_score_modifier`
## Interational organization payments
 - Added `ai_maintenance_value` and `ai_maintenance_ignore_saving`
## Interational organizations
 - Added `owned_location_modifier` block, applies to all locations owned by IO
## Institutions
 - Added `spread_to_market_center` scripted value
## Laws
 - Added `owned_location_modifier` block, only for IO laws, replaces default modifier from IO `owned_location_modifier` block
## Peace treaties
 - Changed `ai_desire` applies to winner now, instead of loser
 - Added `ai_force_add`
## Tests
 - Added `success_child` block, which is checked after a successful test
## Unit types
 - Added `coastal`, `inland`, and `river` terrain types to `combat` and `impact` blocks
## GUI filters
 - Added `hidden_in_searchbar`
 - Clarified `tag`
